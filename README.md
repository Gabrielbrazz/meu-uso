# Meu Uso

Acompanhe o uso das suas assinaturas de IA (Claude, Codex, Cursor, Copilot e outras) direto da barra de menus do Mac.

> **Em construção.** O Meu Uso está sendo preparado como projeto open source em português. A marca nova, a tradução da interface e a documentação chegam nos próximos PRs. Ainda não há versão para baixar.

## Créditos

O Meu Uso é um fork não oficial do [OpenUsage](https://github.com/robinebers/openusage), criado por Robin Ebers e distribuído sob a licença MIT. "OpenUsage" é marca de Robin Ebers; este projeto não é afiliado a ele nem endossado por ele.
